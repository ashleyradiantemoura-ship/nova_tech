IMPORTAÇÃO DO BANCO

1. Abrir o XAMPP.
2. Iniciar o Apache e o MySQL.
3. Acessar o phpMyAdmin.
4. Criar o banco de dados "helpdesk_industrial".
5. Selecionar o banco de dados criado.
6. Clicar em "Importar".
7. Selecionar o arquivo chamados.sql.
8. Executar a importação.


EXECUÇÃO DA APLICAÇÃO

1. Colocar a pasta do projeto em:
C:\xampp\htdocs\devexperience

2. Iniciar o Apache e o MySQL no XAMPP.
3. Abrir o navegador.
4. Acessar:
http://localhost/devexperience/
